# 自分専用DPS版の操作方法

MabiDPS-JP.exeを起動し、アダプターを選択してキャプチャを開始してください。「自分の設定」で、ご自身と確認できた識別IDを選択します。ダメージの大小から自動選択はしません。ゲーム再起動やエリア移動でIDが変わった場合は選び直してください。

オーバーレイは自分の暫定DPS、累計ダメージ、時間、対象イベント数を表示します。「現在戦闘／記録全体」で集計区間を切り替えられます。「初期化」は取得を継続したまま集計をリセットします。「2分タイマー」はアプリ内の時計でありゲーム内効果とは連動しません。既存のドラッグ移動、サイズ変更、最前面、クリック透過を維持しています。

## 実装と未対応の区別

- 自分以外の識別IDを通常の集計・表示から除外します。
- スキル画面は、自分のIDに一致した実際のスキル使用コードと使用回数を表示します。使用回数の範囲は取得セッション全体です。
- 日本版の個々のダメージとスキルの厳密な関連は未特定です。時刻だけで割り当てず、ダメージは「未紐付け」と表示します。正確なスキル別ダメージ表示は未完成です。
- 自分のHP・MP、クリティカル・強打・連打・追加打の発生率は実通信から未取得です。画像の値は埋めず「未取得」と表示します。
- 0x5243は暫定ダメージです。全イベントの意味、回復などの完全な分類は未検証です。0x4FF7は加算しません。
- 保存済み通信の再生では、自分に5473F4を指定し134イベント・274,821の表示を確認しています。今回の新しい実ゲームでの動作確認は未実施です。

数字には公開のPaperlogyフォントをアプリ内限定で読み込み、日本語はWindowsの日本語フォントを使用します。参考画像のフォントを断定したものではありません。PaperlogyはOFLで配布されており、同梱のPaperlogy-OFL.txtを参照してください。
https://github.com/Freesentation/paperlogy

生通信ファイルは配布ZIPに含めていません。既存のローカル記録機能は維持しています。ゲーム運営の規約上の許可を確認したものではありません。
