# 自動再判定・新オーバーレイ

## キャラクター変更後の判定
従来は手動指定で自動判定がOFFになり、その状態や過去の件数が残る場合がありました。

本版では以下を変更しました。
- 手動で自分を選んだだけでは自動判定をOFFにしません。自動判定のON/OFFボタンで明示的に停止できます。
- キャプチャ開始・初期化では古い自分指定を引き継がず、自動判定を初期化します。
- 判定は直近15秒の活動に限定します。過去の大量ダメージで新IDが負け続けることを防ぎます。
- 選択中のIDが15秒以上、攻撃・スキル通知とも活動せず、別IDに職業の根拠となるスキル情報、直近のスキル通知、3件以上のダメージ通知があり、最後の活動も5秒以内なら、再判定します。
- 選択中IDが活動している間は、他人の火力が高くても乗り換えません。
- 切替後は表示範囲を新IDの直近の活動から開始します。古い集計を混ぜず、保存済み履歴は削除しません。
- 時間指定計測中にID変更と推定した場合は、その計測を中止します。別キャラを混ぜて完了履歴にはしません。

新キャラで職業スキルを含めて攻撃して、再判定を確認してください。判定できない場合、オーバーレイの「再判定」を押すと、現在の表示範囲と自分指定をクリアし、新しい通知で判定し直します。キャプチャやPCAPNGの記録は止めません。「初期化」は取得中の集計も初期化します。

重要：エリア変更・キャラクター変更そのものの通信イベントを特定したわけではありません。同じIDのまま移動した場合や、移動先で攻撃しない場合は自動リセットを保証できません。推定方法のため、他人を選ぶ可能性も残ります。街や混雑エリアでの誤選択がある場合は自動判定をOFFにして手動指定してください。

## オーバーレイ
参考画像の雰囲気を参考に、オリジナルの柔らかい丸角カード、明るい青・黄色のDPS、ミント色の時間、紫の数値、暖色の選択ボタンに変更しました。非公開コード・ロゴ・画像素材は使っていません。右上の「推定／手動」で指定方法を示し、履歴表示や時間指定計測中も下部に表示します。未取得のHP最大値・MP・追加攻撃の値を補完したり、架空のバーを描いたりしません。

ドラッグ移動、サイズ変更、クリック透過、最前面、1〜3分計測、履歴保存は維持しています。ボタン操作ができない場合はCtrl+Alt+Oでクリック透過を解除してください。

## 検証
古い大きなダメージより新IDの活動を優先すること、選択中IDが活動中なら切り替えないこと、根拠が2件以下なら切り替えないこと、再判定境界以前のイベントが表示集計へ入らず元データを変更しないことをテストしました。保存済み通信17本の既存回帰テストも通過しています。
自動テスト99件成功・9件スキップ。Windowsビルドと保存データでのオーバーレイ描画を確認しました。新版の実ゲームでのキャラ変更・エリア変更検証は未実施です。
