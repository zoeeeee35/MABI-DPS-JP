# 公開前のソース確認

確認日 2026-11-13。v1.0.1の更新機能を追加確認しました。以前の項目はv1.0.0時点のレビューを含みます。

## 修正した点

- GoのBrotli依存ライブラリを v1.2.0 から v1.2.7 に更新しました。GO-2026-6888 は、圧縮出力の長さに上限を設けるだけでは抑えられない内部メモリ確保の問題です。修正版に更新したうえで、既存の展開サイズ上限も使います。
- 旧Web版の依存関係を Vue 3.5.45、Vite 6.4.6、Vitest 4.1.12 に更新しました。依存先を含む既知脆弱性を npm audit で再確認しました。
- 設定・日本語辞書・履歴の読み込みを上限付きにし、大きなファイルを丸ごと確保する処理を修正しました。
- 通常のタグなしGoテストが共有の数値表示関数を参照できなかった問題を修正しました。
- README と .gitignore を追加し、利用者の設定・履歴・通信記録・ログ、node_modules、生成されたEXE等を公開ソースから除外しました。

脆弱性情報は [GO-2026-6888](https://pkg.go.dev/vuln/GO-2026-6888) を参照してください。

## 確認範囲

- Windows配布版は `native` タグでビルドします。PCAPNG記録・再生の入口は `capturedev` タグを付けた開発用ビルドに限定しています。
- 配布EXEから、PCAPNG記録・再生の起動オプションが拒否され、対象のファイル操作関数がリンクされないことを確認します。
- ネットワーク取得、TCP再構築、JP9の長さ・圧縮処理、設定引き継ぎ、通知音のパス、ログ出力、履歴保存をレビューしました。
- 通知音の共有パス・デバイスパス・ネットワークドライブ・リパースポイントは再生前に拒否します。設定取り込み時に使えない音声パスは標準音へ置換します。
- 配布Windows版のコードに、ゲーム通信や解析結果を外部サーバーへアップロードする処理は見つかりませんでした。旧オフラインWeb版は127.0.0.1で待ち受け、HostとOriginを検査します。
- 秘密鍵、典型的なAPIトークン、個人のメールアドレス、ユーザーフォルダーの実パス、日時付き実機キャプチャ名を検索しました。公開ソースに該当する秘密情報は見つかりませんでした。テスト用のダミー文字列や第三者コードの作者連絡先は含みます。
- 公開用ZIPにはゲーム通信PCAP、個人設定、戦闘履歴、動作ログを含めません。個々のテストは合成データまたは環境変数で指定する手元の記録を利用します。
- `vendor/` 内のコードと著作権表示は各依存先のライセンスに従います。Npcapのバイナリは同梱していません。

- タグなしGoテストと govulncheck、nativeタグ付き govulncheck。

- 提供されたアプリアイコンの出所と公開許諾は、このコードレビューでは確認できません。
- EXEはコード署名されていません。
- 今回はコードと既存テストのレビューです。網羅的なファジング、第三者による侵入テスト、実ゲームでの更新後の長時間検証は実施していません。
- `docs/` の過去の調査資料には旧バージョンの説明もあります。現行のビルド・公開手順はルートのREADMEを参照してください。

この確認は記載した時点・範囲での結果です。将来の脆弱性や未知の不具合の不存在を保証するものではありません。

## v1.0.1 更新機能の確認

- 更新確認先は zoeeeee35/MABI-DPS-JP の公開Release APIに固定。トークンやゲーム通信・設定・履歴・ログは送信しません。HTTPS通信時の接続元IP等はGitHub側に見えます。
- 起動時の確認は初期ON、24時間に1回。設定から無効化可能。適用はユーザー承認後のみ。時間指定計測中は更新を開始しません。
- ダウンロード先とHTTPSリダイレクト先を制限。GitHubのasset digest、ZIPの実サイズ、VERSION、manifestのEXEハッシュを照合。ダウングレードとプレリリースは選択しません。
- ZIPのパストラバーサル、絶対パス、Windowsデバイス名、代替データストリーム、重複パス、リンク、許可外ファイルを拒否。サイズ・件数にも上限。
- 設定・履歴は更新の対象外。既存CSV・config・soundsを保持。置換エラー時はバックアップから復元するテストを実施。
- 公開中v1.0.0のZIPをHTTPSで取得し、SHA-256と28ファイルを検証。取得したEXEは実行していません。
- 実行中アプリと競合しないテスト専用mutexをビルド時に設定し、ローカルで作成したダミーEXEを用いた更新ヘルパーの終了待ち・置換・再起動を検証。CSVと履歴の保持を確認。
- GitHubで実際に新しい版を公開して行う本番更新は未検証。更新署名・コード署名は未導入。GitHubアカウント/Releaseの侵害、電源断からの自動回復までは保証しません。
- 外部ツールから抽出した個人利用用の識別子辞書は、公開用ソースZIP・配布ZIPには含みません。オプション読込機能のみ含みます。
- HTTPクライアントの追加により検査対象となったGO-2026-6859（HTTPサーバーの競合条件）への予防対応として、ビルド要件をGo 1.27.4に更新。native版はHTTPサーバーを起動しません。

## v1.0.2 自動開始の確認

- 既存のゲームプロセス所有TCP接続とアダプターIPの照合を使い、自動開始の候補を限定。ゲーム未接続時は待機し、複数候補が解決できない場合は手動選択を待ちます。
- 列挙をバックグラウンドで行い、通常は5秒間隔で接続を確認。Npcapの権限を自動変更したり、UACを迂回したりしません。
- 手動停止とサンプル切り替え時は自動再開を抑止。古い列挙結果で誤って開始しないよう世代番号を照合。サンプルGUIテスト中は自動開始しません。
- デバイス選択・手動停止・非同期開始の回帰テスト、Go native/タグなしのテスト、vet、Windowsビルド、サンプルGUI検証を実施。
- 自分IDは従来の自動推定を使用し、ローカル所有者を確定したものではありません。ローカル通信2本では、解析済みの送信スキル通知から自分IDを直接確定できる根拠は得られませんでした。
- 実ゲームを起動するところからの自動開始、混雑時の自分ID判定精度は未検証。誤判定時は手動修正が必要です。通信内容の保存機能は追加していません。
