# 敵味方判定用・手動停止記録版

画像のA/B/C・30秒記録欄を「敵味方判定用の記録を開始」「記録を停止して保存」に変更しました。DPS集計・プレイヤー分類は従来どおり維持します。未分類の通信もPCAPNGへ保存します。

1. このフォルダーの MabiDPS-JP.exe を起動し、「取得設定」を開きます。
2. ゲームへログイン済みの状態でアダプターを選び、キャプチャを開始します。
3. 「敵味方判定用の記録を開始」を押します。ログインやアカウント操作中は記録しないでください。
4. 自分の攻撃・被弾・回復・他プレイヤーの攻撃など、調べたい状況を通常の手動操作で発生させます。可能なら操作の時刻と内容をメモすると、後で照合しやすくなります。
5. 必要な場面が揃ったら「記録を停止して保存」を押します。30秒では自動停止しません。キャプチャ停止・アプリ終了でもファイルを閉じて保存します。

保存場所はEXEと同じ場所の captures/session-番号/ 内です。classification-年月日-時分秒-番号.pcapng と、件数・容量・開始終了時刻のメタデータJSONを作成します。再度開始すると別のファイルを作り、前回を上書きしません。画面にも保存先・経過秒数・件数・容量・停止理由を表示します。

保存内容はゲームプロセスに関連付けたTCP16000の送受信パケットです。TCP再構築前のパケット、時刻、シーケンス番号、ペイロードを保持するため、後から解析を変更できます。PCAPNGを再生して未識別IDやスキルとの対応を調べられます。保存しただけで敵味方の自動判定が完成するわけではありません。

時間制限はありませんが、容量保護のため1記録64MiBで自動停止します。必要なら改めて記録を開始してください。従来の30秒記録ロジックは互換用に内部へ残し、通常画面からは隠しました。ローカルPCAP再生のパケット上限も100万件へ拡張しました。DPSイベントの集計上限など既存の解析上限は別に残るため、長い記録は複数に分けることを推奨します。

「このフォルダーの記録を削除」は、キャプチャ停止後に使用できます。このアプリの旧A/B/Cファイルと、所定の命名規則の判定用記録・メタデータのみを削除します。無関係のファイルは削除しません。生通信が機密情報を含む可能性があるため、外部送信やクラウド同期先への配置は避けてください。この機能が外部へアップロードすることはありません。

検証：30秒を超える90秒時点のテストパケットを保存し、PCAPNG再生で730の候補イベントを復元する自動テスト、非上書き、削除対象の限定、64MiB上限のテストを追加しました。既存の全自動テスト・go vet・Windowsビルド・サンプルGUI再生を実行しています。実ゲームで長時間記録する新しい実機検証は行っていません。
