# HP更新対応版

## 起動
MabiDPS-JP.exeを展開先で起動し、従来どおりアダプターを選択して取得を開始します。「自分の設定」でご自身と確認できるIDを選択してください。今回のファイルでは563F8Bが自キャラ候補ですが、自動で固定はしていません。HP更新を受信するとオーバーレイに現在HPを表示します。最大HPとMPは未取得です。HPの割合は推測しません。

## 実装
既存の接続・方向別TCP再構築を維持。9バイト受信フレームの分割・結合を処理し、フラグ1はサイズ制限付きBrotli展開を試行します。成功した内容を解析します。展開できない形式は従来の生ペイロード解析を維持しており、すべてのフラグの意味が確定したわけではありません。

0x1D596は21バイト、Resource Type=8のみHPとして扱い、Entity IDごとに現在値・前回値を保持します。0x5243の+16はuint64 LEとして読み取り、HP減少と対象ID・前後1秒以内・数値完全一致で一対一の照合を行います。時刻はフレームを完成させたキャプチャ時刻であり、ゲーム内の発生時刻ではありません。TCP欠落後は既存の安全停止を維持します。再送はTCP再構築で除外し、同じ数値の別イベントは除外しません。0x4FF7およびHP差分はDPSへ追加しません。

DPS側の既存上限（1イベント10億）は維持し、それを超える値は切り捨てず除外します。敵味方・回復を含む全イベント種別の確定、スキル別ダメージ、最大HP・MPは引き続き未完成です。名前は解析していません。

## 添付実通信で確認
自キャラ候補563F8BのHP更新14件。提示された19842、19159、18567、14366、13447、12091を確認。ファイル全体でHP更新62件、対象ID・時刻・差分の照合候補52件、Brotli展開成功64フレーム。52件すべての画面値照合を完了したという意味ではありません。

テストでは分割されたBrotliフレーム、64bit値、HP差分の重複加算防止を検証しました。保存データの検証であり、新版での実ゲーム画面確認は未実施です。生通信ファイルはこの配布物に含めていません。
