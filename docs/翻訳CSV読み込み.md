# CSVでスキルの日本語表示を変更する

## ファイルの配置

MabiDPS-JP.exe と同じフォルダーに「スキル翻訳.csv」を置いてください。
この版には、247種類の内部名の一覧と、出典を照合して記入した132行の和名・原型名を同梱しています。

例：

    MabiDPS-JP.exe
    スキル翻訳.csv
    config/

通常の編集ではJSON変換やEXEの作り直しは不要です。

## 編集手順

1. アプリの「設定」から「翻訳CSVを開く」を押します。エクスプローラーでCSVを直接開いても構いません。
2. 「日本語訳」列を書き換えます。「内部名」は対応付けのキーなので変更しないでください。
3. 「CSV UTF-8（コンマ区切り）」形式で保存します。Excelブック形式や通常の文字コードのCSVに変えないでください。
4. 記録中なら停止して保存し、MABI DPS JPを終了します。
5. EXEを起動し直します。次の起動時に編集後のCSVが読み込まれます。
6. 設定の「スキル表示名のCSV設定」で読み込み件数を確認できます。

アプリ起動中の自動再読込は行いません。保存しただけで表示が変わらない場合は再起動してください。

## 列の意味

| 列 | 編集する内容 |
| --- | --- |
| 内部名 | 通信で取得した英語名。変更しないでください。 |
| 職業候補 | 作業用の分類。職業判定を変更する設定ではありません。 |
| 日本語訳 | アプリへ表示する名前。空欄は従来辞書の名称、対応がなければ内部名を表示します。 |
| 確認状態 | 対応の確認状況を管理するためのメモ。今回の直接読込方式では、要確認・未確認でも日本語訳が記入されていれば表示に使用します。 |
| 備考 | 出典・対応根拠・派生名の注意など。アプリの表示名そのものには加えません。 |

「日本語訳」列の名前は表示だけに使います。内部ID、ダメージ、DPS、スキルの紐付け・グループ分けは変更しません。
同じ日本語訳にした複数の内部名も、データ上は別々の識別子のままです。

## 今回の132行について

和名表記は日本版のGameWith各職業記事を参照しています。職業の正式表記はNEXON公式サイトを照合しています。
資料には通信の内部名は掲載されていないため、内部名との対応が確定したものとは扱っていません。Tier・強化などの派生は原型名である旨を備考に残しています。
「確認状態」は自動的に確認済みへ変更していません。実機で対応を確認できた行は、管理用に確認済みへ変更できます。
残る空欄を推測だけで埋める処理はありません。

## 読み込みの優先順位

1. EXEと同じフォルダーの「スキル翻訳.csv」に記入された日本語訳
2. 従来の config/skill-name-ja.json とEXE内の辞書
3. 英語の内部名

従来の9列の翻訳一覧CSVも、見出しがそのままなら「スキル翻訳.csv」という名前で使用できます。
内部名／日本語訳の2列だけのCSVにも対応しています。
CSVを別のフォルダーへ置いた場合や、名前を変更した場合は読み込まれません。

## 読み込めない場合

UTF-8以外の文字コード、壊れた引用符・列数、同じ内部名に異なる訳が複数ある場合などは、CSV全体を適用せず従来辞書へ戻ります。設定画面に原因を表示します。
ファイル上限は4MiB、翻訳行は10,000行までです。日本語訳の中に改行を入れないでください。

アプリはこのCSVを自動で上書きしません。
更新時はCSVをバックアップし、自分で編集したCSVを残してください。新版同梱のCSVを上書きすると、自分の編集内容が置き換わります。

## 検証内容

- 132件をEXE起動時に読み込み、日本語名が画面へ反映されることを確認。
- CSVの名前だけを2回変更し、EXEを再起動するたびに表示名が変わることを確認。
- 不正なCSVでエラーが表示され、従来辞書へ戻ることを確認。
- 保存済み実通信の3戦闘について、変更前後の総ダメージ・計測時間・DPSが一致。
- サンプル再生、ソート、時間選択、オーバーレイ等の既存GUI検証を維持。

配布用CSVには、元の翻訳一覧にあった通知回数・出現ファイル数、プレイヤーID、アカウント情報、実通信ログを含めていません。
