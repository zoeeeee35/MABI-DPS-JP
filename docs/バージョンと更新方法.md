# バージョンと更新方法

アプリ名は MABI DPS JP。v0.1.0から版番号を付けて管理しています。
画面上部、設定画面、EXEのプロパティ→詳細で確認できます。

- 不具合修正：末尾を増やす（例 0.1.1）。
- 機能追加：中央を増やす（例 0.2.0）。
- 互換性のない大きな変更：先頭を増やす。
- 翻訳データは別に r1、r2…で管理。CSVを直接編集した場合は「CSV編集あり」と表示。

## 更新するとき

1. アプリを終了。
2. 配布ZIPを新しいフォルダーへ展開。
3. 以前の「スキル翻訳.csv」を、新しいEXEと同じフォルダーへコピーすると編集内容を引き継げます。
4. 履歴が必要なら「data」、記録が必要なら「captures」フォルダーもコピー。
5. 新しいEXEを起動し、設定画面の版番号とCSV読込状態を確認。

新しい翻訳行と以前の編集を両方利用する場合は、CSVの「内部名」をキーに手動で統合してください。
配布ZIPには個人の設定・履歴・通信記録を入れません。

## 開発時

VERSIONがアプリ版番号の唯一の入力元です。TRANSLATIONS_VERSIONが配布翻訳データの版番号です。
変更時はCHANGELOG.mdに内容を記載し、package-native.ps1でビルド・テスト・版番号付きZIPを生成します。
スキル翻訳.csvは出力先に既存ファイルがある場合、ビルド時にも上書きしません。
release-manifest.jsonには配布時点の版番号・ビルド日時・SHA-256を保存します。個人のパスは含めません。
後からCSVを編集すると配布時のハッシュとは異なりますが、起動時に読み込まれる正常な動作です。

## 未翻訳の表示

スキル翻訳.csvの日本語訳が空欄なら、英語の内部名をそのまま表示します。空欄指定は従来のJSON辞書より優先します。日本語を記入すると、次回起動時から日本語表示になります。CSVに行が存在しないスキルは、従来辞書に訳があればそれを使い、なければ内部名を表示します。

## 効果IDの翻訳と未分類内訳

設定の「効果ID翻訳CSVを開く」で効果ID翻訳.csvを編集します。CSV UTF-8で保存し、アプリを再起動してください。
職業はIceMage、Priest等の内部接頭辞または日本語職業名、効果IDは0x付き16進数、日本語訳は表示したい名前です。
日本語訳が空欄、IDが未登録、職業が一致しない場合は未分類内の効果ID別行に残ります。ゼロ値には名前を登録できません。
職業 * は全職業への明示指定です。通常は職業を限定してください。正式名称未確認の訳は推定と付けてください。
未分類の▶をクリックすると▼になり内訳を表示します。親行は合計、子行は内訳であり、ALLへ重複加算しません。
更新時はスキル翻訳.csvに加え、編集済みの効果ID翻訳.csvもコピーしてください。

## 1体へのDPSを表示する

「スキル」画面上部の「対象：すべて ▼」を押し、プルダウンから対象IDを選ぶと1体に絞ります。「すべての対象」で解除します。
対象候補は現在の表示区間で自分のダメージが届いた相手だけです。記録全体を選ぶと記録全体の候補を確認できます。
木人の位置・名前とIDの対応は未解析です。1体だけ通常攻撃し、件数・累計・最終命中時刻の変化から選んでください。
選択した対象へのダメージだけでDPSを再計算しますが、分母は元の戦闘時間・時間指定の計測時間と共通です。
スキル使用回数は対象候補が一致する通知だけを数え、対象不明の使用通知は数えません。ダメージのヒット数とは別です。
フィルターは表示用です。履歴と元データには全対象を残します。履歴を開いたときも対象を選べば絞り込めます。
自分のIDやセッションが変わった場合は全対象へ戻します。同じセッションで対象が消えた場合は選択を維持し、命中がなければ0です。必要なら新しい対象を選択してください。

## スキル別の円グラフ

分析画面に、表示区間のスキル別ダメージ割合を表示します。スキル画面で対象を絞った場合も同じ条件です。
扇形へマウスを置くと小窓でスキル名全文・総ダメージ・割合を表示し、離すと消えます。長い名前は折り返します。
未分類は親の合計だけを円グラフへ含め、ALLと内訳の子行は含めません。小さいスキルも円に含め、凡例は上位8項目までです。

## 召喚の結界の予定通知（v0.2.0）

設定→結界通知で「結界通知」をONにしてください。初期状態はOFF、事前通知は5分前です。
毎時00分（日本時間）の予定を通知します。ゲーム通信や実サーバーの開催を検知するものではありません。
事前1/3/5/10/15/30分、開始時通知、Windows通知、音、バナー・ヘッダー表示を個別に設定できます。
標準では事前時刻からヘッダーに時計を表示します。「常時カウントダウン」をONにすると常に次の毎時00分まで表示します。
音声はWAV/MP3を選択・試聴でき、音量はアプリ内の音声再生だけに適用します。Windowsトースト自体の音声は常に無音で二重再生を防ぎます。
音声ファイルはコピーせずパスをdata/barrier-settings.jsonへ保存します。削除・移動した場合は再選択してください。
Windows通知を初めて送信すると、自分のスタートメニューにMABI DPS JP.lnkを作成し、専用の通知IDを登録します。管理者権限は不要です。
Windows通知は集中モードや通知の許可設定に従います。表示されない場合はWindows側の通知設定も確認してください。
「事前バナーを試す」「開始バナーを試す」は音・Windows通知なしでバナーを確認します。「Windows通知を試す」はトーストのみを送信します。
アプリが起動している間に動作します。スリープや終了中の過去通知をまとめて出すことはありません。DPSオーバーレイを隠しても通知設定は有効です。
更新時は必要に応じてdata/barrier-settings.jsonも引き継げます。配布ZIPには個人の設定・音声ファイルは含めません。

### v0.2.1の結界通知
上部操作行の「結界通知 ON/OFF」で有効・無効を切り替えます。詳細は「オーバーレイ → 結界通知」から設定できます。従来の「設定 → 結界通知」も利用できます。Windows通知が表示されない場合は「Windows通知を試す」を押し、画面下の状態番号を確認してください。


### v0.2.2
1・2・3分を選び「開始」を押すと、5秒の準備カウント後に指定時間を計測します。「中止」で準備をキャンセルできます。
結界の標準通知音は sounds/Inspiration02-1(High).mp3 です。以前の独自音声設定は保持します。標準音へ戻すには「オーバーレイ → 結界通知 → 標準音へ戻す」を押してください。効果音の権利表記は「効果音クレジット.txt」を参照してください。
