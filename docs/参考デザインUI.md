# 参考画像に合わせた日本語UI版

旧版で記録中の場合は停止・保存し、旧版を終了してから、このフォルダーのMabiDPS-JP.exeを起動してください。ブラウザやWebView2は不要です。実通信取得には従来どおりNpcapが必要です。

## 画面の変更

- 細い左サイドバーと上部の接続バーへ再構成しました。
- 最上部でネットワークアダプターを選択し、右のボタンでキャプチャを開始・停止します。候補が確認できない場合は勝手にループバックを選ばず、選択待ちにします。
- オーバーレイ表示、クリック透過、現在の戦闘／記録全体の切替を上部に集約しました。
- 分析タブに、操作バー、対象範囲、3つの統計カード、率の指標、グラフ、ランキング、スキル表、バフ表を配置しました。
- 下部の内容はマウスホイール、または右のスクロールバーで表示します。プレイヤー行をクリックするとスキルタブへ移ります。
- 取得設定をダークテーマの設定ページへ統合しました。記録開始・停止・PCAPNG読込を通常画面で操作でき、白い旧取得設定ウィンドウを開く必要はありません。
- 開発者向け診断は「詳細設定・開発者向け診断」にまとめました。互換用の旧詳細画面は明示的に開く操作だけ残しています。敵味方の手動分類ダイアログとOSのファイルダイアログは既存のネイティブ補助画面を継続します。
- オーバーレイ設定に不透明度のスライダーを配置しました。Ctrl+Alt+O、Ctrl+Alt+Hも引き続き使用します。旧版との同時起動ではホットキーが競合するため、切り替えて使用してください。
- スクリーンショットボタンは自アプリの画面だけをPNGへ保存します。ゲーム画面やデスクトップ全体は撮影しません。

## データの扱い

今回の変更は表示・操作画面です。JP9、0x5243、職業推定、個人別集計、戦闘履歴、手動停止PCAPNG記録を維持します。

火炎術師などの未取得ダメージは引き続き「未取得」です。未対応のクリティカル・追加打・強打・連打・バフや、実ダメージとの対応が未特定のスキル分析を、架空の数値や0%で埋めていません。参考画像のロゴ・画像・非公開コードは使用していません。

## 検証

- Windowsビルド・go vet・従来サンプルGUI再生が成功。
- 自動テスト74項目成功（サブテスト・ローカル実通信回帰を含む）、失敗0、スキップ0。
- 実EXEで保存済みPCAPNGを再生し、取得済み274,821と火炎術師の未取得状態を維持することを確認。
- 設定ページ遷移、詳細設定の開閉、アダプター選択を自アプリの操作処理で検証。通常操作では旧取得設定ウィンドウが非表示であることを確認。
- メイン画面、設定画面、スクロールした下部、詳細設定を自アプリ描画で画像へ出力し、配置・日本語表示を確認。

player-main.pngは保存済み実通信の再生表示です。capture-settings.pngが統合した設定画面、analysis-details.pngがスクロールしたスキル・バフ表です。

今回、新しい実戦闘キャプチャは行っていません。実OSの125%・150%表示倍率や、すべてのマルチモニター構成での実機確認は未実施です。必要なら -classic-ui で旧標準画面へ戻せます。生通信は配布ZIPへ含めません。
