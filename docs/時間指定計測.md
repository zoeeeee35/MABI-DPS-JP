# 時間指定計測と履歴保存

以前の1分・2分・3分は単独のカウントダウンで、DPSや履歴とは連動していませんでした。本版では時間指定の集計と履歴保存へ接続しました。

## 操作
1. キャプチャを開始し、自分のIDが自動推定または手動指定された状態にします。
2. オーバーレイの「1分」「2分」「3分」を押すと、その時点から選んだ時間の計測が始まります。「開始」でも選択済みの時間で開始できます。
3. 途中の無攻撃時間も含めて、60秒・120秒・180秒を計測します。対象IDは開始時の自分に固定し、途中の自動選択で別人へ切り替えません。
4. 終了すると「時間指定 60秒」等の履歴を自動保存し、その結果を表示します。DPSはその区間のダメージ合計÷選択秒数です。

開始時刻以上・終了時刻未満のイベントだけを対象にします。開始前のダメージ、終了時刻以後のダメージは入りません。通常の自動戦闘履歴も従来どおり保存され、時間指定履歴とは区別されます。追加のダメージを発生させたり二重加算したりする機能ではありません。

実行中の残り時間ボタンを押すと中止します。別の時間ボタンを押すと、その時点からやり直します。中止分を完了済み1分の履歴としては保存しません。キャプチャ停止・初期化・手動での自分ID変更でも時間指定計測は中止します。キャプチャ自体は時間指定の終了時に停止しません。

履歴は区間内のイベントを保持し、再起動後の読込でも同じ集計時間を再現します。スキル・判定候補の表も選択した履歴の区間が対象です。従来の暫定解析という性質は変わりません。

## 検証
60秒・120秒・180秒それぞれについて、開始前／終了境界のイベント除外、途中の無攻撃時間を含むDPS、保存・再読込、0ダメージ区間、不正な区間の拒否を自動テストしました。既存のテストとWindowsビルドも実施しました。
新しいEXEでの実ゲームの1〜3分計測確認は未実施です。
