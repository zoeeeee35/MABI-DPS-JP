# 折りたたみ履歴とHP・MP表示

## 履歴の操作
「分析」の左の「履歴 ▸」を押すと左に履歴一覧を開きます。もう一度押すか一覧内の「閉じる」で隠せます。分析ページを開いたまま記録を選べるようにし、以前の独立した履歴タブは外しました。

日時・職業・時間・ダメージ・場所メモで記録を選びます。選ぶと履歴パネルを閉じ、分析ページ全体にその結果を表示します。履歴を開いている間、マウスホイールは履歴一覧に作用します。「前へ／次へ」でも一覧を送れます。場所メモの編集や一覧の全体表示は下部の「一覧・場所メモ」から利用できます。

ライブ表示へ戻る場合は「現在戦闘／記録全体」の切り替えを使ってください。既存の日時・職業・日本語スキル名・並べ替え・履歴保存は維持しています。

## HPの現在値
既存の取得処理は、0x1D596の21バイトの通知でResource Type=8の場合に、Entity IDと現在HP（+12、uint64 LE）を読み取ります。自分のIDに一致する最新の値を、実通信のオーバーレイへ表示します。

キャプチャ開始後にHP更新通知が来ていない場合、その時点のHPを取り出せているわけではありません。「受信待ち／更新待ち」と表示します。被弾や回復等に伴う通知が受信できれば更新します。今回、既存の実通信を再生し、自キャラ候補のHP更新14件を再確認しました。HP取得アルゴリズムを新たに変更したわけではありません。

最大HPは未特定です。現在値の過去最大を最大HPとみなす処理は入れていません。HP更新を履歴へ保存する機能も未実装なので、履歴表示中は「履歴は未記録」と表示し、ライブの別時点のHPを過去の値として表示しません。

## MPの現在値
MPに対応するメッセージID・Resource Type・値の配置は、まだ特定できていません。「未解析」と表示します。根拠のない数値や0で埋めていません。

## 確認
既存テスト・Windowsビルドを実行しました。保存済み通信を再生したアプリで、履歴の開閉、履歴選択後の分析表示、既存設定への移動を確認しました。新版の実ゲームでの確認は未実施です。

旧履歴を引き継ぐ場合は、アプリを終了して既存フォルダーのEXEとconfigを更新してください。data・capturesと場所メモの.locationファイルは残してください。
