# 履歴表示と日本語スキル辞書

## 履歴
「戦闘3」等の番号を一覧から外し、記録日時（日本時間）、職業、計測時間、総ダメージ、DPSを表示します。時間指定の履歴は「時間指定 60.0秒」等で区別します。

受信時刻が残っている履歴は、イベントの受信時刻と記録内の相対時刻から戦闘開始時刻を表示します。時刻情報のない旧履歴は保存日時に「（保存）」を付けます。記録日時の新しい順に並びます。職業は履歴に残る情報を利用し、不明なものは「職業不明」とします。

場所の自動解析は未対応です。「場所メモ」から「カカシ・訓練場」「○○ダンジョン」などを手入力できます。メモは自動取得した場所ではありません。履歴JSONと同じフォルダーの「元ファイル名.json.location」に保存します。元の戦闘JSONは変更しません。履歴を移動・バックアップするときは、この.locationファイルも一緒に扱ってください。

## 日本語スキル表示
添付のmabinogi_skill_name_ja.jsonをconfig/skill-name-ja.jsonとして統合しました。known_aliasesの31件だけを優先して表示します。all_internal_candidatesや18職の参考一覧から未確定の対応を補完することはありません。未知の内部名はそのまま表示します。辞書自体は表示候補であり、すべての日本版公式名を照合済みという意味ではありません。

MeleeDefaultAttack_1〜3は、辞書の通常攻撃（近接1〜3段目）を表示します。複数候補がこの具体的な内部名だけの場合は「通常攻撃（近接・スキル群）」と表示します。0x772815F3などの識別子だけを見て通常攻撃と断定する処理はありません。

内部名、候補名リスト、識別子、集計キー、スキル紐付け処理、DPS計算は維持しています。同じ和名になる別内部名も勝手に合算しません。スキル使用のみの行と、ダメージが紐付いた行の両方が表示変換の対象です。並べ替えも日本語の表示名で行えます。

config/skill-name-ja.jsonのknown_aliasesは編集可能です。変更後はアプリを再起動してください。EXEの横に辞書がない場合は埋め込み辞書を利用します。

## 更新方法
既存の履歴を使う場合はアプリを終了し、今までと同じアプリフォルダーのEXEとconfigを更新してください。既存のdata・capturesは残してください。別フォルダーへ展開した場合、そのままでは以前のフォルダーの履歴は表示されません。

## 検証
known_aliasesの適用、未確定・未知名の保持、識別子だけで通常攻撃へ分類しないこと、内部データの不変性、履歴日時の日本時間表示、受信時刻の復元、場所メモの保存・再読込と戦闘集計の不変性をテストしました。保存済みPCAPNG17本で既存のDPS回帰テストも通過しています。
自動テスト104件成功・9件スキップ。Windowsビルドと履歴・日本語スキル表・場所メモ入力画面を確認済みです。画像は保存済み通信の再生によるものです。新版での実ゲーム確認は未実施です。
