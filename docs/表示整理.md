# 表示整理版

変更した点：
- オーバーレイの現在戦闘・記録全体・スキル・再判定・初期化・時間選択・開始ボタンの文字を白へ変更しました。選択色も読みやすい濃さへ調整しました。
- メインウィンドウのタイトルバーを暗いネイビー、タイトル文字を白に設定しました。WindowsのDWM機能を利用しています。
- スキル画面の大きな「ダメージ判定候補」枠を外し、スキル表を上へ詰めました。
- 詳細な判定統計とCSV出力は「設定 → 詳細設定・開発者向け診断 → 判定フラグの検証・CSV」へ移動しました。
- オーバーレイの「クリ候補／強打候補／連打候補」を「クリティカル／強打／連打」へ短縮しました。計算・ビット判定の意味や精度は変えていません。判定は実測仮説であり、詳細設定の検証表示では候補として扱います。
- HP・MPの右端の横棒を削除しました。最大HPやMPが未取得の場合、その状態は表示に残します。
- オーバーレイ右上の「推定／手動」バッジを削除しました。自動判定や手動指定の内部処理は維持しています。

DPS計算、スキル紐付け、日本語辞書、履歴・場所メモ、1〜3分計測、クリック透過などの機能は維持しています。

既存テスト・Windowsビルドが成功し、保存済み通信の再生画面でオーバーレイとスキル画面を確認しました。詳細設定から判定検証へ移動できること、タイトルバーのダークモード・色指定APIが成功することも確認しています。タイトルバーを含む画面全体のスクリーンショット確認と、新版での実ゲーム検証は未実施です。

タイトルバーの色指定はWindowsの対応状況に依存します。利用したAPIと対応情報：
https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute

以前の履歴を引き継ぐ場合はアプリを終了し、同じフォルダーのEXEとconfigを更新してください。既存のdata・capturesと場所メモの.locationファイルは残してください。
