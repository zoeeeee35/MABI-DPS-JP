# MABI DPS JP

日本版マビノギモバイルで、自分のDPSやスキル別ダメージを確認できるWindows用ツールです。ゲーム画面上に小さく表示する「ミニ表示」と、詳しい数値を表示する「通常オーバーレイ」を切り替えられます。

**[Windows版 v1.0.5をダウンロード](https://github.com/zoeeeee35/MABI-DPS-JP/releases/download/v1.0.5/MABI-DPS-JP-v1.0.5-Windows.zip)**

[リリース一覧](https://github.com/zoeeeee35/MABI-DPS-JP/releases)からもダウンロードできます。

## 動作環境

- Windows 10 / 11、64ビット版
- 日本版マビノギモバイルのPCクライアント
- 通信取得用ソフトの [Npcap](https://npcap.com/)

配布されたEXEを使う場合、GoやNode.jsなどの開発環境のインストールは不要です。

## 初めて使うとき

1. 上のリンクから `MABI-DPS-JP-v1.0.5-Windows.zip` をダウンロードします。
2. ZIPを右クリックし、「すべて展開」を選びます。
3. [Npcap公式サイト](https://npcap.com/#download)からインストーラーをダウンロードし、インストールします。Npcapは別途配布されているソフトです。
4. 展開したフォルダー内の `MabiDPS-JP.exe` を起動します。EXEと同じフォルダーにある設定・翻訳・音声などのファイルも一緒に置いてください。
5. 初回起動で設定の引き継ぎを聞かれたら、初めて使う場合は「いいえ」を選びます。更新の場合は「はい」を選び、旧版のフォルダーを指定できます。
6. ゲームにログインすると、ゲーム接続のあるアダプターで自動的にキャプチャを開始します。後からゲームを起動した場合も接続を待ちます。
7. ゲームで攻撃すると、自分のIDが自動推定されてDPSが更新されます。自動開始できない場合だけ、アダプターを選び「キャプチャ開始」を押してください。

Npcapの導入に問題がある場合も、「サンプル再生」で画面の動作を確認できます。

## 基本操作

| やりたいこと | 操作 |
| --- | --- |
| DPS・累計ダメージを見る | 「分析」を開く |
| スキルごとのダメージを見る | 「スキル」を開く。列の見出しで並べ替え可能 |
| 攻撃対象を絞る | 分析・スキル画面の「対象」を選ぶ |
| 自分の判定を変更する | 「設定 → 詳細 → 自分IDを修正」で自分のIDを選ぶ |
| 終了した戦闘を見る | 「履歴」を開いて選ぶ |
| オーバーレイの種類を変える | 上部の「通常表示／ミニ表示」を切り替える |
| オーバーレイを隠す | 「表示」をオフにする |
| ミニ表示の位置を変える | 「オーバーレイ」で「位置調整／常に表示」をオンにし、カードをドラッグ |
| オーバーレイの見た目を変える | 「オーバーレイ」の「カードの見た目と位置」を開く |
| 1・2・3分で計測する | 通常オーバーレイで時間を選び「開始」。5秒の準備カウント後に計測開始 |
| 戦闘終了までの待機時間を変える | 歯車の「設定」→「計測」 |
| 旧版の設定を引き継ぐ | 歯車の「設定」→「その他」 |

クリック透過がオンのときは、オーバーレイ上のボタン操作やドラッグができません。操作するときはメイン画面から切り替えてください。

## 召喚の結界通知

上段の「結界通知」から、事前通知のタイミング、音声、音量、バナーなどを設定できます。初期状態では通知と常時カウントダウンがオンです。保存済みの設定がある場合は、その設定を使います。

通知は日本時間の毎時00分を基準にした予定通知です。実際のサーバー上の開催状況を検出する機能はありません。

## 計測値について

自分のIDの自動推定は、混雑した場所で他のキャラクターを選ぶ場合があります。表示がおかしいと感じたら「設定 → 詳細 → 自分IDを修正」を確認してください。

スキルの分類とクリティカル・強打・連打・追加攻撃の判定には、実測に基づく暫定処理が含まれます。追加攻撃率は「追加攻撃件数 ÷ 追加攻撃以外のヒット数」です。判定フラグが取得できたヒットを使って計算します。

## 翻訳・保存データ・更新

- スキル名は `スキル翻訳.csv` と `効果ID翻訳.csv` で編集できます。UTF-8形式で保存してアプリを再起動してください。未翻訳のスキルは英語の内部名を表示します。
- 設定・戦闘履歴・動作ログは、EXEの横の `data` フォルダーに保存されます。
- 更新時は旧版を終了し、新しいZIPを別フォルダーに展開します。設定は初回起動時、または「設定 → その他」から引き継げます。
- 設定引き継ぎの対象は表示・計測・結界通知の設定です。戦闘履歴も残す場合は、アプリを閉じた状態で旧版の `data/history` を新しい版の同じ場所へコピーしてください。
- 戦闘データ・設定・ログは自動で外部へ送信しません。起動時にGitHubへ公開Releaseの更新確認を行います。「設定 → その他」で無効にできます。不具合報告にログを添付する場合は、内容を確認してください。

さらに詳しい操作は [使い方.txt](使い方.txt) を参照してください。

## 開発環境

Goの開発環境が必要です。必要バージョンは [go.mod](go.mod) に記載しています。Windows版の検証環境は Go 1.27.4 / Windows amd64 です。

ソースを展開したフォルダーでPowerShellを開き、次を実行します。

~~~powershell
.\build-native.ps1 -Go go
~~~

Goテスト、静的検査、Windows EXEのビルド、サンプル再生によるGUI検証を実行します。出力先は `dist-native` です。

配布ZIPを作成する場合は次を実行します。

~~~powershell
.\package-native.ps1 -Go go -OutRoot .\release-output
~~~

通常のWindows版は `native` ビルドタグを使用します。PCAPNGを扱う開発者向け機能は、`capturedev` タグを追加したときに有効です。

~~~powershell
go test -tags native ./...
go vet -tags native ./...
go build -tags "native capturedev" -o MabiDPS-JP-dev.exe .
~~~

`web` フォルダーは旧オフラインWeb表示のソースです。Web側を変更する場合は、このフォルダーで次を実行します。

~~~powershell
npm ci
npm test
npm run build
~~~

利用者の設定・履歴・通信記録・ログをリポジトリに追加しないでください。除外項目は `.gitignore` に記載しています。

## アプリの更新

v1.0.1以降は、起動時にGitHubの最新版を1日1回確認します。新版がある場合は「設定 → その他」に案内を表示します。「更新する」を押して確認した場合だけZIPを取得し、キャプチャを停止してファイルを入れ替え、再起動します。手動確認と自動確認の無効化も同じ画面で行えます。

既存のdataフォルダー、翻訳CSV、config、soundsは保持します。CSVの初期データも既存ファイルがある場合は更新しないため、新版で追加された翻訳は必要に応じて手動で取り込んでください。未保存の計測中の結果は更新前に保存し、時間指定計測は終了してください。

更新には、このリポジトリの公開・正式ReleaseとGitHubが返すSHA-256が必要です。タグはv1.2.3形式、ZIPはMABI-DPS-JP-v1.2.3-Windows.zip形式にしてください。ActionsからダウンロードしたMABI-DPS-JP-Windows.zip（内部にそのバージョンのZIPとSHA256SUMS.txtのみを含む形式）にも対応します。ZIP内のVERSIONとrelease-manifest.jsonも同じバージョンにする必要があります。

ZIPは64MiB以内、展開後は192MiB以内に制限します。更新中のファイルと旧ファイルのバックアップは、EXE横の .updates/pending-* に残ります。書き込みエラー時は復元を試みますが、電源断などによる中断からの自動復旧は保証しません。起動できない場合は、元の配布ZIPを別フォルダーに展開し、dataを引き継いでください。

HTTPS・取得元制限・SHA-256照合は行いますが、コード署名や独立した鍵による更新署名は未導入です。GitHubアカウントやリリース自体が侵害された場合を防ぐものではありません。実通信の更新適用は、公開された新しいReleaseで別途確認する必要があります。
## キャプチャの自動開始（v1.0.2以降）

起動時は自動開始ON・自分IDの自動推定ONです。ゲームプロセスが接続しているネットワークアダプターを検出してキャプチャを開始します。ゲームを後から起動しても約5秒間隔で接続を確認します。複数候補がある場合は以前選んだアダプターを優先し、判別できなければ手動選択を待ちます。Npcapは別途必要です。

キャプチャ停止を手動で押した場合、その起動中は勝手に再開しません。再開はキャプチャ開始、または自動開始を一度OFFにしてONにしてください。設定 → 計測から自動開始と自分ID自動推定を変更でき、data/capture-start.jsonへ保存します。サンプル再生中と自動GUIテスト中は自動開始しません。

自分IDは、既存の職業・スキル・ダメージ通知を使った推定です。ローカルプレイヤーIDを通信から確定したものではなく、混雑した場所や同行NPCがいる場面では他の対象を選ぶ可能性があります。設定 → 詳細 → 自分IDを修正で確認・修正できます。自動推定前のダメージも同じIDの記録から遡って集計します。
