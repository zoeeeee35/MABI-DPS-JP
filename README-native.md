# 実受信実験版の使い方

日本版の正確な戦闘ダメージ取得はまだ完成していません。既存アプリに受信・識別・解析・診断の経路を追加した開発版です。

## 起動と取得

1. 起動中の古いMabiDPS-JPを終了します。複数起動するとホットキーが競合します。
2. 展開した`MabiDPS-JP.exe`を起動します。ブラウザーは不要です。既存履歴を継続するなら、元のEXEと同じフォルダーへ配置し、`data`を残してください。
3. 日本版マビノギモバイルを通常どおり起動・ログインします。
4. MabiDPSの「キャプチャ設定」を開きます。
5. 「ゲーム接続あり」と表示されたアダプターを選択します。このPCの実機確認ではRealtek Gaming 2.5GbEでした。番号はPC環境によって変わります。
6. 地域は「日本版 / 韓国旧形式の互換性検査」を選び、「キャプチャ開始」を押します。
7. ゲームへ戻り、敵を数回攻撃します。
8. MabiDPSの設定に戻り、件数と状態を確認します。
9. 「キャプチャ停止」を押します。「診断JSONを保存」で状態・件数を保存できます。

## 候補が抽出された場合

「検出した攻撃者」から、自分またはパーティに対応するものを確認し「集計対象へ追加 / 除外」を押します。元のキャラクター名は収集していないため、表示は「未確認の攻撃者1」等です。スキルIDは未確認のまま表示する場合があります。

敵・NPCが攻撃者として含まれる可能性があるので、自動的に全候補をプレイヤーとしてランキングへ入れません。対象を追加すると、保持している同一セッション内のイベントも再集計します。候補を抽出できたことだけで、ダメージ解釈やプレイヤーの正しさが確定したことにはなりません。

イベント候補が0件の場合、「集計対象へ追加」を押してもDPSは出ません。UIの問題とは限りません。

## 診断の読み方

- アダプター利用不可：選択アダプターが切断・無効・Npcapから開けない状態です。
- 権限不足：Npcapから権限エラーが返っています。設定や実行権限を確認してください。保護機能を無効にする必要はありません。
- 通信未受信：取得パケットが0です。使用中アダプターとゲーム起動状態を確認します。
- 対象ゲームを識別できない：WindowsのTCP所有情報から対象プロセスの接続を見つけられていません。
- ゲーム通信受信・既知戦闘形式は未検出：対象プロセスの受信はあるものの、現在選択した旧形式での戦闘デコードに至っていません。
- 戦闘イベント候補を抽出：候補は得られましたが、集計対象の選択や照合が必要です。
- DPS集計中（解釈未検証）：選択した候補が集計へ届いています。実画面との照合は別に必要です。

「解析失敗」は、認識した構造を解析して失敗した件数です。既知のフレーム自体が見つからない場合、候補0・失敗0のままになることがあります。「旧形式の目印」も併せて確認してください。

「TLS形式接続」が増えても、ゲーム全体が暗号化されているとは限りません。そのストリームの復号は行いません。全体のプロトコルや暗号化は未確定です。

「受信」はアダプター上で取得したTCP/UDPの合計件数で、ゲーム以外・送信側も含みます。「ゲームTCP」は対象プロセス所有の受信方向に合致した件数です。UDPはゲーム所有の待受に合う受信候補数だけを表示します。UDPの内容・ダメージは解析しません。

## 保存と制限

生パケット・IP・ポート・元のプレイヤーID・認証情報を診断ファイルへ保存しません。実受信イベントが集計対象となり戦闘が終了した場合は、仮名化済みのイベントを`data/history`へ保存します。`liveVerified:false`、`source:capture-experimental`として未検証であることを保持します。

取得は32ストリーム、攻撃者64件、イベント20,000件等に制限しています。上限や欠落が表示された場合は完全な結果として扱わず、停止・リセットして再試験してください。リセットしても保存済み履歴は消しません。

サンプル再生は維持しています。「サンプル再生」「データ読込」「リセット」を選ぶと、実受信を停止して切り替えます。サンプルで順位が変わっても実ゲーム対応の証明にはなりません。

このPCではNpcapが既に導入されていたため、追加導入は行っていません。Npcapを同梱していません。未導入環境の取得機能にはNpcapが別途必要ですが、サンプル機能は取得とは独立しています。

今回の攻撃テストでは、約730ダメージを含む5〜10回の攻撃という申告に対して、戦闘候補は0件でした。現行日本版のダメージ取得は未完成です。UDP診断は、その原因が別経路かどうか調べるための追加機能で、DPS対応済みの機能ではありません。
